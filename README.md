# Browser-readable firmware

Generated by `release-firmware.yml`; do not edit or merge.

These are the same images attached to release `v1.5.1`,
republished here because GitHub serves release downloads
without the CORS header a web page needs to read them. The
hosted flasher fetches them from raw.githubusercontent.com,
which does send it.

Force-pushed on every release. Holds the newest few tags,
the current one always among them; older directories are
pruned. The releases themselves remain the archive, so
firmware pruned from here is still downloadable from its
release.
